## Описание проекта

«Астероиды» — двумерная аркадная игра на Python и Pygame. Пилот управляет кораблём, уклоняется от астероидов и сбивает их ракетами, набирая очки и сохраняя жизни.

## Функциональные возможности

### Основной функционал

- Заставка и запуск игры щелчком по кнопке на ней.
- Корабль с вращением, ускорением и инерцией.
- Выстрелы ракетами в направлении корабля.
- Случайные астероиды с линейным и угловым движением.
- Переход объектов через границы игрового поля.
- Столкновения, анимация взрыва, счёт и три жизни.
- Завершение и повторный запуск игры.

### Управление

| Клавиша | Действие |
| --- | --- |
| Стрелка влево / вправо | Повернуть корабль |
| Стрелка вверх | Ускорить корабль |
| Пробел | Выстрелить |
| Щелчок по кнопке заставки | Начать или перезапустить игру |

## Требования к системе

- Python 3.9 или выше.
- Windows, macOS или Linux с графической средой.
- Pygame 2.6.1.

## Установка и запуск

```bash
git clone https://github.com/vantuzov/asteroids.git
cd asteroids
python -m venv venv
```

Активируйте виртуальное окружение:

```powershell
venv\Scripts\activate
```

В macOS или Linux:

```bash
source venv/bin/activate
```

Установите зависимости и запустите игру:

```bash
pip install -r requirements.txt
python main.py
```

## Структура проекта

```text
asteroids/
├── README.md
├── requirements.txt
├── main.py
├── settings.py
├── entities.py
├── game.py
└── tests/
```

- `main.py` — точка входа.
- `settings.py` — параметры игрового поля и физики.
- `entities.py` — корабль, астероиды, ракеты и взрывы.
- `game.py` — окно, игровой цикл, обработка событий и правила игры.
- `tests/` — тесты игровой логики.

## Пример использования

Создайте и активируйте виртуальное окружение, установите зависимости и выполните `python main.py`. На заставке нажмите кнопку, чтобы начать игру; управляйте кораблём стрелками и стреляйте пробелом.
